# FAQ Chatbot

Python-based FAQ Chatbot using NLP, TF-IDF Vectorization and Cosine Similarity.

## Features

- Interactive chatbot
- FAQ matching
- NLP-based processing
- Fast responses

## Technologies Used

- Python
- NLTK
- Scikit-Learn
- TF-IDF
- Cosine Similarity

## How to Run

1. Install dependencies

pip install nltk scikit-learn

2. Run

python faq_chatbot.py
